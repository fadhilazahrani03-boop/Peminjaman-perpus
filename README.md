# Peminjaman-perpus

Aplikasi manajemen peminjaman buku perpustakaan berbasis web yang dibangun menggunakan framework **Laravel** dan basis data **MySQL**.

---

## 🌟 Fitur Utama

- **Autentikasi User**: Fitur Login dan Logout yang aman.
- **Manajemen Hak Akses (Role-Based)**:
  - **Admin**: Mengelola data buku, peminjaman, pengguna, serta operasi CRUD keseluruhan.
  - **User / Anggota**: Melihat daftar buku dan status peminjaman.
- **Fitur CRUD**: Pengelolaan data buku, peminjaman, dan anggota secara terstruktur.

---

## 🛠️ Teknologi & Stack

- **Framework**: Laravel
- **Bahasa Pemrograman**: PHP
- **Database**: MySQL
- **Frontend**: Blade Template / HTML / CSS / JavaScript
